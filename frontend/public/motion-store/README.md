# LuxeFashion cinematic store MVP

Self-contained preview of the approved motion storefront and connected shopping pages. The existing React application remains unchanged by this addition.

Run the frontend's existing development server, then open `/motion-store/motion-proof.html`. The catalog entry is `/motion-store/luxefashion-preview.html#/new`.

The folder can also be served by a plain static HTTP server. Keep the HTML files and `assets/` together so relative links and media resolve.

Includes cinematic scrolling, continuous image motion, liquid-glass treatments, rounded product previews, category navigation, product detail pages, wishlist, bag, demo checkout, editorial pages, the shared animated footer and a floating back-to-top control. Motion respects the operating system's reduced-motion preference.

Shopping, newsletter and account behavior are local demos. No payment is collected, order sent, email delivered or production account created. Bag/wishlist/language data use browser storage.

Asset provenance and licenses are in `assets/SOURCES.md` and the accompanying license files. Review notes are included beside these entry files.
